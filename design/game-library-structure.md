# PandoraBox 游戏扩展与分组设计

## 目标

首批游戏从 5 个扩展到 11 个：

- 五子棋
- 围棋
- 象棋
- 中国跳棋
- 飞行棋
- 黑白棋
- 国际跳棋
- 数独
- 华容道
- 2048
- 井字棋

当前实现已按 `design/game-plugin-architecture.md` 的插件协议接入 11 个本地插件；后续新增游戏应继续走 manifest + async loader，不再由大厅入口直接 import 游戏实现。

游戏数量增加后，首页需要从“纯列表”升级为“可筛选、可继续、可扩展”的游戏库。

## 首页信息架构

首页保留 `PandoraBox 棋局匣` 顶部品牌区，右上角仍然是设置入口。品牌区下方不放全局难度和模式，所有对局参数都在点击游戏后的开局弹窗里选择。

首页主体按这几层组织：

1. `继续对局`
   - 只在存在本地存档时展示。
   - 展示最近 1-3 个未完成对局。
   - 卡片信息：游戏名、模式、难度、上次时间、继续按钮。

2. `分类筛选`
   - 横向可滑动胶囊 tabs。
   - 默认选中 `全部`。
   - 分类包括：全部、经典棋局、跳跃竞速、益智解谜、数字休闲、快速对弈。

3. `游戏分组列表`
   - 在 `全部` 下按分组展示。
   - 在单一分类下只展示该分类游戏。
   - 每个分组标题右侧显示数量，例如 `经典棋局 · 5`。

4. `底部导航`
   - 游戏大厅
   - 棋局记录
   - 收藏夹
   - 我的

## 分类设计

### 经典棋局

偏策略、棋盘对弈、适合人机 AI 难度分层。

- 五子棋
- 围棋
- 象棋
- 黑白棋
- 井字棋

### 跳跃竞速

棋子移动规则明确，强调路径、跳跃、骰子或路线推进。

- 中国跳棋
- 国际跳棋
- 飞行棋

### 益智解谜

偏单人解题，有关卡、步数、提示或撤销。

- 数独
- 华容道

### 数字休闲

偏轻量、短局、重复游玩。

- 2048

### 快速对弈

可作为交叉分类，不一定独立成首页大组。用于筛选短局游戏。

- 井字棋
- 黑白棋
- 2048

## 游戏卡片信息

每个游戏配置需要包含：

```js
{
  id: "reversi",
  title: "黑白棋",
  category: "classic",
  secondaryCategories: ["quick"],
  complexity: "中等",
  modeSupport: ["ai", "local"],
  difficultySupport: ["easy", "medium", "hard"],
  progressType: "match",
  icon: "./public/skins/guofeng-ink/icons/reversi.svg",
  subtitle: "夹击翻子，终局多子获胜",
  rules: []
}
```

字段说明：

- `category`：首页主分类。
- `secondaryCategories`：搜索或筛选用的交叉分类。
- `complexity`：大厅展示的上手复杂度。
- `modeSupport`：是否支持单人 AI、本地双人或纯单人。
- `difficultySupport`：是否有难度。数独、华容道、2048 的难度含义与棋类不同。
- `progressType`：用于存档和继续对局展示。

## 开局弹窗设计

所有游戏点击后都进入居中开局弹窗。

不同游戏展示不同参数，不再所有游戏强塞同一套控件。

### 对弈类弹窗

适用：

- 五子棋
- 围棋
- 象棋
- 中国跳棋
- 飞行棋
- 黑白棋
- 国际跳棋
- 井字棋

控件：

- 对战模式：单人对弈 / 本地双人
- 难度：简单 / 中等 / 困难
- 规则入口
- 开始按钮

围棋额外：

- 棋盘规格：9 路 / 13 路 / 19 路

飞行棋额外：

- 玩家数量：2 / 3 / 4

### 单人益智类弹窗

适用：

- 数独
- 华容道
- 2048

控件：

- 难度或关卡
- 是否开启提示
- 是否允许撤销
- 开始按钮

数独：

- 简单 / 中等 / 困难 / 专家

华容道：

- 入门 / 标准 / 困难

2048：

- 目标：2048 / 4096
- 棋盘：4x4 首版，后续可加 5x5

## 新游戏实现策略

### 黑白棋

优先级：高。

原因：

- 规则稳定。
- AI 易做出明显难度差。
- 移动端棋盘适配简单。

首版能力：

- 8x8 棋盘
- 合法落子提示
- 自动翻子
- 无合法步自动跳过
- 终局计分
- AI：角落优先、边线权重、可翻子数、稳定子启发

### 国际跳棋

优先级：中高。

首版建议采用 8x8 英式跳棋规则：

- 黑格行走
- 普通子斜向前走
- 吃子强制
- 到底升王
- 王可前后斜走一格

后续可扩展国际规则。

### 数独

优先级：中高。

首版能力：

- 9x9
- 候选数笔记
- 冲突高亮
- 一键检查
- 提示
- 难度题库生成或内置题库

### 华容道

优先级：中。

首版能力：

- 经典横刀立马
- 拖拽或点击移动
- 步数统计
- 撤销
- 关卡选择

### 2048

优先级：高。

原因：

- 实现快。
- 移动端手势体验好。
- 适合验证益智类框架。

首版能力：

- 4x4
- 滑动合并
- 分数与最高分
- 撤销一步
- 本地存档

### 井字棋

优先级：中。

定位：

- 快速对弈
- AI 教学与低龄用户入口

首版能力：

- 3x3
- AI 简单/中等/困难
- 困难难度不可战胜

## 数据结构

建议把游戏目录升级为：

```text
src/games/
  registry.js
  categories.js
  gomoku/
  go/
  xiangqi/
  chinese-checkers/
  flying/
  reversi/
  draughts/
  sudoku/
  klotski/
  2048/
  tictactoe/
```

`registry.js` 只管游戏元信息与入口。

`categories.js` 只管分类展示：

```js
export const categories = [
  { id: "all", title: "全部" },
  { id: "classic", title: "经典棋局" },
  { id: "race", title: "跳跃竞速" },
  { id: "puzzle", title: "益智解谜" },
  { id: "number", title: "数字休闲" },
  { id: "quick", title: "快速对弈" }
];
```

## 视觉设计

第二套“水墨玉章”下，游戏分组不建议用大色块区分，而用：

- 轻量分组标题
- 细玉色分隔线
- 小号分类印章
- 游戏卡片中使用对应棋类插画

分类色：

- 经典棋局：玉绿
- 跳跃竞速：石青
- 益智解谜：朱砂
- 数字休闲：鎏金
- 快速对弈：淡墨
