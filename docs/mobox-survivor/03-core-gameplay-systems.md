# 核心玩法系统设计

## 1. 操作设计

推荐操作方式：

- 竖屏。
- 全屏拖动移动。
- 自动攻击。
- 主动技能按钮右下。
- 暂停按钮右上。
- 不使用固定虚拟摇杆作为默认方案。

原因：

- 割草生存需要最大化战斗画面。
- 触摸拖动比固定摇杆更节省空间。
- 自动攻击降低操作门槛，技能选择和走位承担策略深度。

移动规则：

- 玩家按触点方向移动，不瞬移到触点。
- 松手后角色停止或保持低速惯性，MVP 建议停止。
- 拖动区域覆盖整个画布。
- UI 按钮区域拦截触摸，避免误触移动。

## 2. 关卡推进

关卡不能只按时间结束。推荐使用“战斗积分进度 + 目标进度 + Boss 节点”。

通关进度来源：

- 击杀普通怪。
- 击杀精英怪。
- 完成关卡目标。
- 击败 Boss。
- 净化事件物。

示例：

- 普通怪：1 分。
- 精英怪：20 分。
- 事件目标：50 到 100 分。
- Boss：直接触发通关或给大量进度。

原型中的镇夜进度已经拆成击破、精英、目标、鬼王和事件五类来源，并在 HUD、续玩摘要和结算中展示主要来源。

这样做有两个作用：

- 玩家知道这局主要靠什么推进，而不是只看到一个百分比。
- 策划调关时可以发现来源占比是否失衡，例如普通击杀过强会让地图目标失去意义。

优势：

- 玩家不能靠绕圈拖时间过关。
- 高输出构筑能更快推进。
- 任务型玩法更容易加入。

## 3. 单局节奏

建议每关 4 到 8 分钟。

早期关卡：

- 3 到 4 分钟。
- 技能池少。
- 怪物行为简单。
- Boss 机制单一。

中期关卡：

- 5 到 6 分钟。
- 技能进化变常见。
- 精英词缀出现。
- 关卡目标开始组合。

后期关卡：

- 6 到 8 分钟。
- Boss 多阶段。
- 地图事件更频繁。
- 玩家需要完整构筑才能通关。

节奏段落：

1. 0% 到 20%：安全起步，教当前关卡机制。
2. 20% 到 45%：怪潮压迫，第一次精英。
3. 45% 到 70%：目标压力，精英组合。
4. 70% 到 90%：Boss 前压迫波。
5. 90% 到 100%：Boss 或最终任务。

## 4. 升级三选一

升级时暂停战斗，居中展示三张符牌。

候选池：

- 未拥有的主动匣术。
- 已拥有匣术升级。
- 被动属性。
- 满级后转化为铜钱、治疗或临时增益。

抽取规则：

- 前 3 次升级提高新技能出现率。
- 如果玩家拥有可进化组合，提升相关被动出现率。
- 不给完全无意义选项。
- 稀有选项需要有清晰视觉。

重掷：

- 每局有限免费次数。
- 可通过遗物、天赋或激励广告获得额外次数。

## 5. 匣术体系

匣术是本游戏的技能统称。

类型：

- 弹道：镇魂飞刃、铜钱镖。
- 环绕：朱砂符阵、护身轮。
- 领域：青灯结界、血月护身咒。
- 召唤：纸人傀儡、铜兽机关。
- 点名：惊雷符、判官笔。
- 链式：锁魂链、雷链。
- 辅助：招魂幡、魂灯。

每个匣术必须回答：

- 解决什么战斗问题？
- 面对哪类敌人强？
- 面对哪类敌人弱？
- 升级后爽点是什么？
- 进化后视觉差异是什么？

## 6. 进化系统

进化条件：

- 主技能达到指定等级。
- 拥有指定被动或遗物。
- 击败 Boss 或开启高品质宝箱。

进化示例：

- 镇魂飞刃 + 暴击 = 千刃镇魂阵。
- 朱砂符阵 + 生命 = 血月护身咒。
- 鬼火灯 + 冷却 = 九幽鬼火海。
- 锁魂链 + 范围 = 无常锁界。
- 纸人傀儡 + 数量 = 百纸夜军。
- 惊雷符 + 穿透 = 天罚雷箓。
- 判官笔 + 经验 = 生死一划。

进化反馈：

- 暂停战斗。
- 魔盒打开。
- 符阵展开。
- 进化技能第一次自动释放。
- 屏幕给短暂慢动作和音效。

## 7. 敌人行为矩阵

基础行为：

- 追击：向玩家移动。
- 包围：沿切线移动，试图形成圈。
- 冲锋：蓄力后直线突进。
- 远程：保持距离发射弹幕。
- 分裂：死亡产生小怪。
- 治疗：为附近怪物回血。
- 护盾：正面减伤或周期护盾。
- 潜行：接近前半透明或不可见。
- 爆炸：死亡后延迟爆炸。
- 召唤：周期产生小怪。

行为组合示例：

- 纸人 = 追击 + 分裂。
- 灯笼鬼 = 远程 + 漂浮。
- 夜叉 = 追击 + 冲锋。
- 缝尸匠 = 远程站位 + 治疗。
- 鬼轿 = 冲锋 + 召唤。
- 影鬼 = 潜行 + 背刺。

## 8. 抗性和弱点

伤害系别：

- 斩
- 火
- 雷
- 咒
- 影
- 灵
- 机关

抗性规则：

- 普通怪不需要复杂抗性，避免早期困惑。
- 中期开始部分怪物对某类伤害有 20% 到 40% 抗性。
- 弱点命中有额外受击反馈。
- 图鉴明确提示弱点。

示例：

- 纸人怕火和雷。
- 骨奴怕灵和机关破甲。
- 影鬼怕灯火、结界和灵系。
- 戏伶鬼怕雷，抗咒。

## 9. Boss 设计原则

Boss 不能只是血厚。每个 Boss 至少需要：

- 1 个识别性攻击。
- 1 个阶段变化。
- 1 个可反制窗口。
- 1 个与章节主题绑定的机制。
- 1 个死亡奖励或剧情推进。

Boss 阶段：

- 100% 到 70%：展示核心机制。
- 70% 到 35%：加入组合机制。
- 35% 到 0%：狂暴或机制加速。

反制方式：

- 击破弱点。
- 站到安全区域。
- 击杀召唤物。
- 净化场地物。
- 利用章节机制。

PandoraBox 原型中的 Boss 弱点窗口：

- Boss 转阶段时开启较长弱点窗口。
- Boss 大招结束后开启较短弱点窗口。
- 弱点窗口内所有伤害提高，命中 Boss 对应弱点匣术时倍率更高。
- HUD、威胁状态和 Boss 身上的金青色弱点环提示当前可反制时机。
- 例：尸山鬼王弱寒咒、护身轮和地煞雷符；黑伞夜君弱疾步走位后的远程飞刃和纸人傀儡。

## 10. 局外成长

局外成长要提供长期目标，但不能让玩家靠数值碾压忽略局内选择。

模块：

- 镇夜天赋：基础属性。
- 角色修行：角色特性。
- 魔盒修复：系统解锁。
- 百鬼图鉴：弱点和背景。
- 法器收藏：影响局内遗物池。
- 剧情残页：主线和角色记忆。

成长边界：

- 局外成长提升舒适度和容错。
- 局内构筑决定单局上限。
- 高难关卡需要策略，不只是战力。

## 11. 失败与复活

失败要让玩家知道为什么死。

结算展示：

- 死亡来源。
- 最大伤害来源。
- 本局最高击杀技能。
- 推荐提升方向。
- 本局获得资源。

复活规则：

- 每局最多 1 次免费或广告复活。
- 复活后短暂无敌。
- Boss 战复活保留 Boss 当前阶段，但清理部分小怪。
