# 美术、UI 与音频方向

## 1. 视觉定位

东方志怪 + 都市长夜 + 朱砂符箓 + 青绿鬼火。

不要做成传统仙侠，也不要做成纯恐怖。更适合的方向是现代城市被古老阴间规则侵入：便利店、高架桥、地铁站和写字楼仍然存在，但被招魂幡、符纸、鬼火、旧戏台、鬼市摊位覆盖。

## 2. 色彩体系

主色：

- 黑玉：背景、魔盒、深夜。
- 朱砂：攻击、危险、封印。
- 青绿鬼火：魂火、灵体、技能高亮。
- 暗金铜锈：奖励、法器、边框。

辅助色：

- 月白：文字、光源、守护灵。
- 暗紫：梦境、诅咒、深层鬼域。
- 锈红：血月、Boss、危机事件。

避免：

- 全屏黑导致看不清。
- 大面积土棕导致发脏。
- 所有技能都使用同一绿色。
- 仙侠金光过多。

## 3. 角色设计原则

移动端小屏幕下，角色必须先保证轮廓。

原则：

- 强轮廓。
- 大色块。
- 一个代表物件。
- 攻击方向清晰。
- 受击和死亡反馈明确。

角色锚点：

- 沈灯：短刀、镇魂铃、青绿符光。
- 白烬：鬼纹、破斗篷、赤色鬼火。
- 陆青岚：机关箱、铜兽、符雷线圈。
- 阿照：纸灯笼、守护灵、月白光。
- 无名判官：判笔、残卷、黑金官服。

## 4. 怪物设计原则

每个怪物谱系必须有不同轮廓和运动方式。

- 游魂：软、飘、透明、消散。
- 饿鬼：低、快、扑、撕咬。
- 纸人：薄、抖、裂、纸屑。
- 灯笼鬼：圆、浮、亮、爆火。
- 骨奴：硬、重、碎、骨响。
- 影鬼：细、暗、闪、黑烟。
- 戏伶鬼：高、袖、唱、音波。
- 夜叉：宽、角、冲、重击。

PandoraBox 原型已接入第一批百鬼动态识别层：

- 游魂：两侧游丝摆动，死亡为“魂散”。
- 灯笼鬼：翅翼扇动，死亡为“灯灭”。
- 纸人：纸片抖动，死亡为“纸碎”。
- 骨奴：身体裂纹，死亡为“骨裂”。
- 毒灯鬼：毒泡漂浮，死亡为“毒散”。
- 红伞妖：伞骨辐射和爆裂倒计时，死亡为“伞爆”。
- 夜叉：冲锋刃线和方向尖角，死亡为“刃断”。
- 无头将：盾弧高亮，死亡为“甲碎”。
- 缝尸匠：治疗十字和范围圈，死亡为“针断”。
- 戏伶鬼：准星/弦线，死亡为“弦断”。
- 画皮鬼：面具环和精英光圈，死亡为“画皮裂”。
- Boss 护卫：显示“护”字环；裂隙刷怪显示紫色裂隙环；背刺刷怪显示红色警示箭。

## 5. 技能视觉分类

- 符箓系：朱砂线条、符纸飞散、阵纹。
- 鬼火系：青绿火焰、拖尾、爆燃。
- 雷法系：蓝白闪电、短促高亮。
- 机关系：铜色机械、齿轮、弹壳。
- 纸人系：白纸、红墨、撕裂。
- 判官系：黑金笔锋、墨迹、审判印。

技能反馈层级：

1. 发射或生成。
2. 命中。
3. 敌人受击色。
4. 击退或硬直。
5. 暴击数字。
6. 死亡爆点。
7. 进化屏幕级特效。

## 6. UI 方向

主界面：

- 魔盒作为中心品牌锚点。
- 章节地图像夜行残卷。
- 角色入口像镇鬼司名册。
- 图鉴入口像百鬼录。
- 天赋入口像魔盒机关盘。
- 商店入口像鬼市摊位。

战斗 HUD：

- 顶部：关卡、进度、血量/经验。
- 中部：战斗画面尽量无遮挡。
- 右上：暂停。
- 右下：主动技能。
- 升级弹窗：居中三张符牌。
- Boss 血条：顶部或上方浮层，不遮挡玩家。

结算：

- 像镇鬼司战后榜文或生死簿残页。
- 展示击杀、存活、奖励、解锁、死亡原因、推荐提升。

## 7. 动效原则

动效要有爽感，但不能影响读图。

优先级：

- 玩家和敌人轮廓永远清楚。
- 危险范围必须比装饰特效更清楚。
- 进化和 Boss 出场可以短暂抢镜。
- 常规命中特效短而密。
- 低端机特效可自动降级。

## 7.1 战斗可读性规范

PandoraBox 原型已验证第一批危险预警语言：

- 夜叉冲锋：冲锋前显示粉红虚线，冲锋中显示红色实线和终点光点。
- 红伞妖爆裂：爆炸前显示橙红危险圈和倒计时扇形。
- 毒灯鬼和戏伶鬼远程攻击：发射前显示到玩家方向的瞄准虚线。
- 缝尸匠治疗：治疗前显示暗金范围圈。
- Boss 大招：Boss 周围显示技能倒计时弧线，冲锋类 Boss 额外显示粗线预警。
- 雷法命中：使用短生命周期闪电线，不只用粒子爆点。

正式项目里这些规则应优先于装饰特效。任何敌人只要有高伤害、控制、爆发、召唤或治疗行为，都必须至少有一种可提前读懂的预警。

## 8. 音频方向

音乐：

- 国风打击乐。
- 电子低频。
- 木鱼、铃铛、唢呐、戏腔作为点缀。
- Boss 战强化鼓点。

音效：

- 魂火拾取：清脆灵光。
- 升级：符纸展开。
- 进化：法阵轰鸣。
- Boss 出场：鼓点 + 鬼啸。
- 纸人死亡：纸裂。
- 骨奴死亡：碎骨。
- 雷法命中：短促电击。

## 9. 资产规格建议

MVP：

- 角色：4 方向移动动画即可，后期扩 8 方向。
- 普通怪：4 到 8 帧移动动画。
- Boss：待机、移动、攻击、受击、死亡、阶段转换。
- 技能图标：128x128。
- UI 图标：矢量或高分辨率位图。
- 地图：章节 tileset + 装饰物。

资源分包：

- 首包：通用 UI、第一章、基础怪、基础技能。
- 分包：后续章节地图、Boss、剧情图、音乐。
